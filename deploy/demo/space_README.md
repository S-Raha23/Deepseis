# DeepSeis

Fault-preserving self-supervised seismic denoising and automated interpretation
(faults, facies) on the real **F3 Netherlands** survey.

This Space is a static demo: every section and number on it was precomputed by
the project's trained models and evaluation code, so it opens instantly and
needs no server.

- Code: [github.com/S-Raha23/Deepseis](https://github.com/S-Raha23/Deepseis)
- Data and checkpoints: [SRaha23/Seismic_Data](https://huggingface.co/datasets/SRaha23/Seismic_Data)

Rebuilt and published from the repository with
`python deploy/demo/build.py && python deploy/demo/push.py`.
